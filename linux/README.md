# 🛡️ Asha Scanner — Linux Desktop & Terminal Edition

**High-Performance Native Cloudflare IP Scanner & Anti-Censorship VPN for Linux**

نسخه بومی، گرافیکی و مستقل **Asha Scanner** برای لینوکس با همان زبان طراحی و امکانات اپلیکیشن اندروید (رابط سایبرپانک، دکمه Arc Reactor، رادار ۳۶۰ درجه، اسیلوسکوپ زنده و سیستم دور زدن سایت‌های ایرانی).

---

## ✨ امکانات گرافیکی نسخه لینوکس (Desktop Features)

* 🎨 **ظاهر و حس دقیق نسخه اندروید (Pixel-Perfect Android Look & Feel):**
  * **تم تاریک سایبرپانک:** پس‌زمینه شبکه نئونی (`#050811`)، رنگ‌های سبز/فیروزه‌ای نئونی (`#00FFC2`) و آبی آسمانی (`#00D2FF`).
  * **دکمه پاور Arc Reactor:** دکمه گرد با حلقه‌های نورانی چرخان و انیمیشن اتصال/قطع.
  * **نمودار ۴ مرحله‌ای Hop HUD:** نمایش زنده مسیر `Device ──> PoW Shield ──> CF Edge ──> Exit Gateway` با پالس‌های لیزری متحرک.
  * **اسیلوسکوپ زنده (Oscilloscope):** ترسیم موجی ترافیک دانلود و آپلود به صورت زنده روی بوم Canvas.
  * **رادار اسکن ۳۶۰ درجه (Radar Sweep Canvas):** اسکن دایره‌ای با رندر پرتو رادار و کشف آنی لبه‌های سالم.
  * **دو زبانه فوری:** دکمه تغییر آنی زبان به **فارسی (RTL)** یا **English (LTR)** با فونت زیبای وزیرمتن (Vazirmatn).

* 🛡️ **امکانات VPN و تونل‌سازی لینوکس:**
  * **پروتکل‌های چندگانه:** Asha PoW ،Aether v2.4 ،MASQUE ،WOM ،WireGuard ،GOOL ،Psiphon ،Tor ،SHARD و Custom Proxy.
  * **دور زدن سایت‌های ایرانی (Bypass Iranian Sites):** تزریق خودکار روت مستقیم به Gateway فیزیکی برای تمام رنج‌های بانکی و دامنه‌های `.ir` (`geoip-iran.cidr`).
  * **کلید قطع اضطراری (Kill Switch):** جلوگیری از نشت IP در صورت قطع تونل.
  * **تله‌متری زنده:** پینگ لحظه‌ای، سرعت دانلود/آپلود و دیتاسنتر خروجی.

* 📡 **اسکنر اختصاصی و جدول نتایج:**
  * تست پکت‌لاس، جیتر، سرعت دانلود و دیتاسنتر (Colo Code).
  * دکمه اتصال مستقیم به عنوان Clean IP برای هر ردیف.
  * خروجی در فرمت‌های CSV ،JSON ،TXT و کپی کانفیگ‌های آماده VLESS/Trojan.

* 🌐 **تیونر DNS (DNS Tuner):**
  * تست پینگ رزالورهای تحریم‌شکن داخلی (شکن، ۴۰۳، الکترو، بگذر، رادار گیم) و بین‌المللی (کلودفلر، گوگل، Quad9).
  * قابلیت اعمال فوری DNS انتخابی روی سیستم.

## 🚀 اجرا در قالب پنجره دسکتاپ (Desktop App Window)

برای اجرای برنامه در قالب **یک پنجره اختصاصی و مستقل دسکتاپ** (بدون تب و نوار آدرس مرورگر):

```bash
cd linux
./asha-linux gui
# یا
make gui
```

### اضافه کردن به منوی برنامه‌های لینوکس (Application Menu)
برای اینکه آیکون Asha Scanner در منوی لینوکس (GNOME / KDE / XFCE / RoFi) ظاهر شود و با یک کلیک باز شود:
```bash
sudo make install
```

## 🖥️ اجرای تحت ترمینال (TUI & CLI)

اگر می‌خواهید در سرور (VPS) یا محیط بدون گرافیک اجرا کنید:
```bash
# منوی تعاملی ترمینال
./asha-linux

# اسکن مستقیم با خط فرمان
./asha-linux scan -count 500 -workers 50 -speedtest
```

> **تضمین سلامت پروژه اندروید:** تمامی کدهای نسخه لینوکس در پوشه `linux/` مستقل هستند و هیچ تاثیری روی سورس‌کد و فرآیند انتشار اندروید (`app/`) ندارند.
